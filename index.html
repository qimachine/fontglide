Design notes / 01

Good typography should arrive without a jolt.

At first, this paragraph is rendered in a dependable system serif. When the custom typeface is ready, the letters change shape. With the crossfade enabled, only the text gently dissolves from one font into the other.

Notice the details: the rhythm of the sentence, the shape of each letter, and the way the words sit together. This is sample copy for comparing the transition, not a promise that every layout will remain fixed.

“The smallest detail can change the feeling of an entire page.”

Try a longer delay to inspect the fallback font first. Then disable the crossfade and reload to see the abrupt swap. Re-enable it to compare the two behaviors under the same conditions.

The preview intentionally includes several text styles. Controls and non-text decoration are not part of the fade.

Demo font: Lobster from Google Fonts. Requires an internet connection for the font stylesheet and font file. If the request fails, the preview remains readable in its fallback font.
